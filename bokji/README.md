# 복지 길잡이

가구 상황을 입력하면 2026년 선정기준으로 받을 가능성이 있는 복지제도를 **판정 근거와 함께** 보여 주고, 정부·지자체에 정책을 제안할 수 있는 공모전과 상시 창구를 모아 둔 정적 웹페이지입니다.

정부 서비스가 아닙니다. 판정은 공개된 기준으로 계산한 추정이며 실제 지원 여부는 신청 후 기관 조사로 결정됩니다.

## 화면

- **내 복지 찾기** (`index.html#find`): 가구, 소득, 재산, 위기 상황을 입력하면 기초생활보장 방식의 소득인정액을 추정하고 제도마다 충족·미충족·확인 필요 항목을 보여 줍니다. 신청은 복지로·정부24·홈택스·고용24 같은 공식 창구로 연결합니다. 가족이 대신 확인하는 모드가 있습니다.
- **정책 공모전** (`index.html#contests`): 접수 중인 정책 제안 공모전을 마감 순으로 보여 주고, 상시 제안 창구와 공모전 모음 사이트를 함께 안내합니다. D-day는 보는 사람의 날짜로 계산합니다.

## 원칙

1. 입력값은 브라우저 안에서만 계산하고 저장하거나 전송하지 않습니다. 서버가 없습니다.
2. 서류 작성·제출 대행, 신청 대리, 유료 상담을 하지 않습니다. 행정사법 제2조 업무에 해당할 수 있기 때문입니다.
3. 결과마다 근거와 출처를 보여 주고, 화면 위아래에 정부 서비스가 아니라는 점과 기준일을 표시합니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `assets/style.css` | 스타일(밝은·어두운 테마) |
| `assets/data-programs.js` | 제도별 기준값(`params`)과 안내 문구·링크·출처(`programs`) |
| `assets/data-contests.js` | 공모전·상시 창구·모음 사이트 목록 |
| `assets/engine.js` | 소득인정액 추정과 제도별 판정 규칙. 숫자는 모두 `params`에서 읽음 |
| `assets/app.js` | 화면 동작, 예시 가구, 공모전 필터 |
| `tests/engine.test.mjs` | 예시 가구로 판정 결과를 확인하는 테스트 |

## 테스트

```sh
node bokji/tests/engine.test.mjs
```

## 해마다 고칠 것

기준값은 `assets/data-programs.js`의 `params`에 모여 있습니다.

1. **매년 7월 말**: 보건복지부가 다음 해 기준중위소득을 고시합니다. `params.median`에 새 해 값을 넣고 `params.year`를 바꿉니다.
2. **매년 1~3월**: 국민기초생활보장 사업안내가 나오면 기본재산액, 주거용재산 한도, 공제액, 자동차 기준을 확인합니다. 기초연금 선정기준액, 아동수당 연령, 근로장려금 기준도 이때 바뀝니다.
3. **공모전**: `assets/data-contests.js`의 `asOf`와 목록을 갱신합니다. 마감이 지난 항목은 화면에서 자동으로 '마감'으로 바뀌지만 목록에서 지우는 것이 좋습니다.

바꾼 뒤에는 테스트를 실행하고, 복지로 모의계산 결과와 한두 가구를 대조합니다.
