# 정책공모 작업실

정부·지자체·공공기관의 정책 제안 공모를 모아 보고, 공모 하나를 골라 Claude와 대화하며 제안서를 쓰는 페이지입니다.

정부 서비스가 아닙니다. 공고 내용은 확인일 기준으로 정리한 것이므로 응모 전에 공식 공고를 다시 확인해야 합니다.

## 화면

- **목록**: 접수 중, 상시 창구, 해마다 열리는 공모, 내 작업으로 나눠 봅니다. 마감 가까운 순이나 상금 큰 순으로 정렬하고 주제·주최·상금·팀 참가로 거릅니다.
- **공고 한 장**: 참여 조건, 참가 형태, 상금, 접수 기간, 공모 내용, 제출물, 제출 방법, 심사, 발표, 생성형 AI 규정, 문의를 같은 순서로 보여 줍니다. 공고에 없는 항목은 '공식 공고에서 확인'으로 표시합니다.
- **Claude와 대화**: 공고 한 장의 내용과 (선택하면) 내 제안서 초안이 Claude에게 함께 전달됩니다. 참여 자격 점검, 아이디어 5개, 근거 자료 찾을 곳, 심사위원처럼 검토 같은 시작 버튼이 있습니다. 답변은 버튼 하나로 제안서 칸에 붙입니다.
- **제안서**: 제목, 한 줄 요약, 현황 및 문제점, 개선 방안, 기대 효과, 실행 방안, 근거 자료 칸이 있습니다. 칸마다 Claude 초안이나 다듬기를 받아 바꾸거나 뒤에 붙입니다. 아래에 공고에서 뽑은 제출 전 점검표가 있습니다.
- **공고 추가**: 공고문을 붙여 넣으면 Claude가 항목을 정리하고, 확인한 뒤 목록에 넣습니다.

## Claude와 쓰는 방식

claude.ai에 게시한 페이지에서는 페이지 안에서 바로 Claude에게 묻고, 대화와 초안을 그 페이지의 저장소에 저장합니다. 그래서 Claude Code 세션에서도 같은 초안을 읽고 이어서 도울 수 있습니다.

브라우저에서 `index.html`을 그냥 열면 Claude를 직접 부를 수 없습니다. 이때는 '대화용 요약 복사'로 공고 요약, 대화 원칙, 내 초안을 한 번에 복사해 Claude 대화창에 붙여 넣습니다. 초안은 그 브라우저에만 저장됩니다.

페이지 안의 Claude에게는 다음 원칙을 함께 보냅니다.

1. 공모 조건은 공고 요약에 있는 사실만 말하고, 없는 내용은 공식 공고 확인을 권합니다.
2. 인터넷을 볼 수 없으므로 통계·법령·예산 수치는 지어내지 않고 [확인 필요]와 확인할 공식 출처를 붙입니다.
3. 공고에 생성형 AI 규정이 있으면 먼저 알려 주고, 제출하는 글은 사용자가 자기 말로 고쳐 쓰도록 돕습니다.

## 데이터

`contests.json`에 공모 45건과 모음 사이트 14곳이 있습니다(2026-11-03 기준).

| 구분 | 건수 | 설명 |
| --- | --- | --- |
| 접수 중·예정 | 24 | 2026년 11월 마감 공모. 4건은 공식 공고를 열지 못해 '공식 공고 미확인' |
| 해마다 열림 | 4 | 국민생각함 정책 아이디어 공모전 등. 2026년 일정 기준 |
| 상시 창구 | 17 | 국민신문고 국민제안, 국민참여예산, 국회 국민동의청원 등 |

각 공모는 같은 항목을 가집니다: `who`(참여 조건), `team`(참가 형태), `limit`(응모 제한), `prize`(`kind`, `top`, `total`, `text`), `start`·`end`·`endTime`(기간), `theme`(공모 내용), `submit`(제출물), `how`(제출 방법), `judging`(심사), `announce`(발표), `aiRule`(생성형 AI 규정), `contact`, `url`, `verified`, `source`, `checkedAt`.

게시된 페이지는 `contests.json`을 기본 목록으로 쓰고, 페이지 저장소의 `contests` 모음에 있는 문서로 덮어씁니다. 그래서 새 공모는 다시 게시하지 않고도 저장소에 문서를 넣어 추가할 수 있습니다. 같은 id 문서에 `hidden: true`를 넣으면 목록에서 빠집니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `page.html` | 화면, 스타일, 동작. `__SNAPSHOT__` 자리에 데이터가 들어감 |
| `contests.json` | 공모 목록 |
| `build.py` | 데이터를 넣어 `index.html`(브라우저용)이나 게시용 파일을 만듦 |
| `index.html` | 만들어진 페이지. 직접 고치지 않음 |
| `tests/data.test.mjs` | 공모 데이터 형식 점검 |

## 만들기와 점검

```sh
node gongmo/tests/data.test.mjs
python3 gongmo/build.py
python3 gongmo/build.py --artifact /tmp/gongmo.html
```

## 목록 갱신

1. 마감이 지난 공모는 화면에서 자동으로 '마감'이 되고 '접수 중' 목록에서 빠집니다.
2. 새 공모는 `contests.json`에 같은 항목으로 넣고 `verified`와 `source`를 정확히 적습니다. 공식 공고를 열어 보지 못했으면 `verified: false`로 둡니다.
3. 해마다 열리는 공모는 새 회차 공고가 나오면 날짜와 시상을 그 회차로 바꿉니다.
